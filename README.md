# Portfolio 8-bit de Ángel Ochoa

Portfolio estático inspirado en los videojuegos clásicos de Pokémon.

## Archivos

- `index.html`: página principal.
- `gaming-variantes.html`: índice con tres maquetas alternativas de portfolio gaming.
- `fantasia-variantes.html`: selector con cinco estilos retro y de fantasía MMORPG.
- `pixel-gremio-opciones.html`: selector con tres propuestas 8-bit en azul y dorado.
- `pixel-misiones-arte.html`: cuatro ideas para reemplazar el arte central del Tablero de misiones.
- `LICENSE`: licencia del proyecto.

Para verlo, abre `index.html` en un navegador. Las fuentes pixeladas se cargan desde Google Fonts cuando hay conexión a internet.

Las propuestas gaming son páginas independientes: `gaming-cyber.html`, `gaming-rpg.html` y `gaming-tactical.html`.

Las propuestas de fantasíaS también son independientes: `fantasia-pixel.html`, `fantasia-gremio.html`, `fantasia-raid.html`, `fantasia-taberna.html` y `fantasia-grimorio.html`.

Las propuestas pixel del gremio son independientes: `pixel-ruta.html`, `pixel-fortaleza.html` y `pixel-misiones.html`.
