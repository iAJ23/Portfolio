# Portafolio de Ángel Ochoa

Este proyecto es una página estática. Para verla, abre `index.html` en un navegador.

## Archivos

- `index.html`: contenido de la página y comentarios por sección.
- `CSS/portfolio.css`: estilos, paleta azul eléctrico y escala de grises, y reglas responsive.
- `images/nosotros/angel.png`: retrato usado en la página.

Bootstrap y las tipografías se cargan desde internet mediante CDN/Google Fonts.
